# 03 — 前端与界面规范

## 1. 页面

- `/`：首页，开始游戏、规则入口
- `/play`：选择本地 AI 或同设备双人模式
- `/world-cup`：本地八人世界杯，支持参赛或纯观战、支持球员高亮
- `/online`：当前在线房间入口的说明页；远程在线服务尚未部署
- `/setup`、`/setup/ai`：选择球员、底板、正手胶皮、反手胶皮
- `/match/:id`、`/match/:id/ai`：同设备双人或 AI 对局
- `/result/:id`、`/result/:id/ai`：对应模式的赛果与逐分战报
- `/rules`：站内规则说明
- `/settings`：音乐开关和音量设置

## 2. 选人/装备

布局重点：不是显示“总战力”，而是显示风格与变化。

- 球员卡：姓名、球员头像、打法标签、基础总点档位。
- 默认只显示阶段摘要；可展开正/反手 60 个底层值。
- 选择底板/胶皮时实时显示差异，例如：`正手·发球旋转 9 → 11 (+2)`。
- 配装确认页显示：球员基础 → 底板 → FH 胶皮 → BH 胶皮 → FH/BH 常驻 → 项目平均战斗值。

## 3. 比赛页核心信息

顶部：

- 局分、当前局比分、发球权、BO 类型、连接状态。

左右：

- 双方球员头像、球员名、底板、两张胶皮。

中央：

- 当前阶段标签。
- 当前 5 个可选进攻项目及其对应防守项目。
- 加点前双方项目基础战斗值，例如：`我的发球旋转 9.5 ↔ 对方旋转判断 10.0`。
- 自己的加点控件；对手只显示“未锁定/已锁定”。

揭晓动画：

```text
发球旋转 9.5 + 4 = 13.5
          VS
旋转判断 10.0 + 1 = 11.0
差值 +2.5 → 未达到 5 → 进入反制
```

## 4. 加点控件

- `+` / `-` 按钮和剩余点数。
- 达到单项上限禁用加号。
- 总预算必须刚好分完才允许锁定（MVP 建议如此，避免忘加点）。
- 锁定前可重置；锁定后不可改。
- 对手锁定只显示状态，不显示分配。

## 5. 相持阶段

当前 Candidate V4 相持加点页同时显示 10 项：5 个进攻 + 5 个防守，共用 `20 + Carry` 点预算；每项进攻各自最多 +4，防守单项不限，只受共享总预算限制。
锁定后最多进行 6 次轮流比较。非当前进攻方只等待，不选择防守技能；防守技能由进攻技能自动映射。比较时先提示进攻能力，再揭晓双方最终值与突破/防守结果；动画节奏统一配置并支持快速显示和跳过。

## 6. 响应式

第一版同时支持桌面和手机浏览器：

- 桌面：三列布局。
- 手机：上方比分，中间对抗卡，底部可滚动加点面板。
- 不依赖 hover 完成关键操作。

## 7. 美术与资源状态

当前网页已接入 `photos/` 中的 8 张球员原图，并处理成 `apps/web/public/assets/players/` 下的 512×512 WebP 头像；React 展示层使用统一映射和缺图回退。`photos/` 原图保持不变。公开仓库或正式发行前，必须核实这些照片的肖像/版权授权；完整盘点见 `docs/10_LEGAL_ASSETS.md`。

球员介绍页和赛事入口可展示新增的 2D 卡通角色及六维能力雷达；比赛视图复用角色立绘、动作姿态与球路特效。素材仅由前端读取，不进入规则数据或 `game-core`。

## 8. 规则、音频与实时信息

- 首页规则入口在站内打开当前可玩 Candidate V4 规则摘要。
- 球员配置页逐项展示正手/反手的球员、底板、胶皮公式与项目平均战斗值。
- Settings 提供跨菜单、选手配置、对局场景切换的六首原创程序化 BGM，并允许静音和调整音量。
- 对局页面底部的公开比赛信息区同步列出双方已经揭晓的攻防值、临时加点、突破结果和比分变化；未揭晓分配不得出现。
- 六轮 Tie Break 的战报必须包含全部六轮已揭晓的双方攻防数值和加点，决胜结果文案使用“六轮相持”。
