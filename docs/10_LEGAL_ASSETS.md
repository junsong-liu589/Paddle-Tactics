# 10 — 素材与公开仓库检查

本文记录当前仓库中可能受第三方权利约束的内容，供把 GitHub 仓库从 Private 改为 Public 或正式发行前核查。

## 当前素材盘点

- **球员照片：** `photos/` 包含 8 张原图；`apps/web/public/assets/players/` 包含对应的处理后 WebP 头像。网页已实际展示这些真实球员照片。它们由项目所有者提供，但仓库尚未记录每张图片的来源、许可证或肖像授权；仅凭文件由项目所有者提供，不能确认公开再分发权。
- **卡通人物：** `apps/web/public/assets/characters/` 中新增了基于上述球员照片参考生成的卡通角色插画。生成过程不会自动取得参考照片、人物肖像或商业使用权；上线前仍需逐一完成照片来源、肖像权、输出内容和目标发行范围的核查。未完成核查前，不应将此更新解读为素材授权已解决。
- **游戏标志照片：** `apps/web/public/assets/brand/paddle-tactics-logo.png` 由项目所有者提供的三人合照经图像编辑遮去球衣上的姓名后生成。遮名不会自动解决原照片的版权、运动员肖像或球衣标识的使用权；公开发布前仍需确认原图来源和授权范围。
- **球员姓名、器材品牌与型号：** `data/` 与 UI 使用真实运动员姓名以及商品品牌/型号作为游戏化配置。数据值代表游戏平衡设定，不代表现实排名、厂商评分或官方背书。公开仓库前仍应核实名称、商标的使用方式和必要免责声明。
- **音乐：** 当前 BGM 是 `apps/web/src/lib/music-player.ts` 里的原创程序化 Web Audio 乐段；没有随项目分发第三方音乐文件。参考方向和来源说明见 `docs/AUDIO_ATTRIBUTION.md`。
- **代码许可证：** 当前仓库根目录没有 `LICENSE` 文件。公开仓库前应由项目所有者选择合适许可证并添加文本；不要默认把代码设为 MIT 或其他许可。
- **配置与凭据：** `.gitignore` 忽略本地 `.env` 文件，Git 历史中能看到的只有 `.env.example` 与 `.env.production.example` 两个模板；模板中的密码与密钥均为占位值。本次按文件路径检查未发现 `.env`、`.env.local` 或 `.env.production` 被跟踪，但这不能证明其他文件或旧提交里绝无密钥，公开前仍应启用 GitHub Secret scanning / Push protection 并复核完整历史。

## 切换为 Public 前的必做事项

1. 为 8 张原图逐一记录来源及允许公开展示、处理和再分发的许可；若无法确认权利，先征得授权或用有明确许可的素材替换原图和处理后头像。
2. 决定项目代码与数据的许可证，并添加根目录 `LICENSE`；同时确认许可范围覆盖哪些目录、报告和素材。
3. 检查球员姓名、品牌/型号、游戏截图及任何第三方标识是否需要免责声明或替换。不要暗示运动员、厂商或赛事官方认可本项目。
4. 在仓库设置 Secret scanning / Push protection，并复核整个 Git 历史中是否曾提交 token、密码或私人文件。当前仅完成配置文件路径与示例内容检查；这不替代 GitHub 的历史凭据扫描。
5. 公开后再检查 Cloudflare Pages 预览链接仍能打开，且静态试玩页不包含服务端密钥。

截至 2026-09-30，**图片授权与代码许可证尚未完成核实**。在这两项解决前，不应把当前仓库直接切换为 Public。静态网页当前已公开可访问；这不等于仓库代码、原始照片或其他文件已获得公开再分发许可。
